# 🎯 Guess the Number Game

A simple JavaScript guessing game where the player tries to guess a randomly generated number.

## 🛠 Tech Stack
- HTML
- CSS
- JavaScript

## 🎮 How to Play
1. Enter a number in the input box.
2. Click the Guess button.
3. Get hints if your guess is too high or too low.
